Sample configuration files for:
```
SystemD: qweercoind.service
Upstart: qweercoind.conf
OpenRC:  qweercoind.openrc
         qweercoind.openrcconf
CentOS:  qweercoind.init
macOS:   org.qweercoin.qweercoind.plist
```
