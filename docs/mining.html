COMPLETE BEGINNER'S GUIDE — NO EXPERIENCE NEEDED

What is mining?

Mining is how new Qweercoins are created. Your computer does a small amount of work to help confirm and record transactions on the network, and in return it earns 69 QWR per block it mines.

Don't worry — you don't need special equipment. Qweercoin uses a simple proof-of-work system that runs fine on a normal laptop or desktop.

Mining rewards take time to mature. After you mine a block, you need to wait for 100 more blocks to be mined on top of it before the coins appear in your balance. This is normal and takes a few hours.

1 Open Terminal

Terminal is a text-based way to talk to your computer. It looks intimidating but you'll only be copying and pasting a few commands — that's it.

On macOS (Mac)

  1. Press ⌘ Command + Space on your keyboard to open Spotlight Search
  2. Type Terminal
  3. Press Enter

A dark window will open with a blinking cursor. That's Terminal — you're ready.

Terminal — zsh
yourname@Mac ~ % ▌

On Windows

  1. Press Windows key + R
  2. Type cmd and press Enter

On Linux

Press Ctrl + Alt + T, or search for "Terminal" in your applications menu.

Tip: To paste into Terminal on Mac, use ⌘ Command + V. On Windows, right-click inside the window.

2 Download Qweercoin

Go to the releases page and download the file for your operating system:

Download Qweercoin

macOS — install from the download

Once downloaded, open Terminal and paste these commands one at a time. After each one, press Enter.

↓ COPY AND PASTE THIS — then press Enter

cd ~/Downloads

↓ COPY AND PASTE THIS — then press Enter

tar xzf qweercoin-v0.1.0-macos-arm64.tar.gz

↓ COPY AND PASTE THIS — then press Enter (you may be asked for your Mac password)

sudo cp qwr-v0.1.0-macos/qweercoind qwr-v0.1.0-macos/qweercoin-cli /usr/local/bin/
When you run the sudo command, your Mac will ask for your login password. Type it (the cursor won't move — that's normal) and press Enter.

Check that the installation worked:

qweercoind --version
If you see something like Qweercoin Core v0.1.0 printed — great, it worked!

3 Start Qweercoin

This command starts the Qweercoin software in the background:

qweercoind -daemon

You should see: Qweercoin Core starting

Now wait about 30 seconds, then check it's running properly:

qweercoin-cli getblockchaininfo

You'll see a bunch of information printed. The important part is "blocks" — that tells you how many blocks are on the chain.

Terminal
% qweercoin-cli getblockchaininfo
{
  "chain": "main",
  "blocks": 247,
  "headers": 247,
  ...
}
If you get an error like "Could not connect to server", the node is still starting up. Wait another 30 seconds and try again.

4 Create Your Wallet

Before you can receive mining rewards, you need a wallet. Think of it like a bank account. Run this command to create one:

qweercoin-cli createwallet "main"

You should see "name": "main" — your wallet has been created.

Get your receiving address

This generates an address where your mining rewards will be sent:

qweercoin-cli getnewaddress

You'll see something like:

Terminal
% qweercoin-cli getnewaddress
qwr1qd8ufzdsrs7lkzt3llq3gj74fksmj228q28fg3g

Copy that address — you'll need it in the next step. It will start with qwr1.

5 Start Mining!

Replace YOUR_ADDRESS_HERE with the address you copied in step 4, then run:

↓ REPLACE YOUR_ADDRESS_HERE BEFORE RUNNING THIS

qweercoin-cli generatetoaddress 1 YOUR_ADDRESS_HERE

That mines one block. To mine continuously and keep going automatically, paste this whole script into Terminal and press Enter:

↓ REPLACE YOUR_ADDRESS_HERE — then copy the whole thing and paste into Terminal

ADDR="YOUR_ADDRESS_HERE"
while true; do
  BLOCKS=$(qweercoin-cli getblockchaininfo | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['blocks'])")
  echo "Mining... current block: $BLOCKS"
  qweercoin-cli generatetoaddress 1 "$ADDR" > /dev/null
done

You'll see it printing Mining... current block: 248 over and over as it works. Leave this running in the background.

To stop mining: click inside the Terminal window and press Control + C.

6 Check Your Balance

Open a new Terminal window (File → New Window, or ⌘ T for a new tab) and run:

qweercoin-cli getbalance

You'll see 0.00000000 at first — this is normal! Your rewards won't appear until 100 more blocks have been mined after yours.

Once enough blocks have passed, you'll see your earnings:

Terminal
% qweercoin-cli getbalance
138.00000000
Each block earns you 69 QWR. The longer you mine, the more you earn!

7 Keep Mining Automatically (Mac)

Don't want to restart mining every time you reboot? These commands set up Qweercoin to start automatically when your Mac turns on.

First, set up the auto-start file (replace YOUR_USERNAME with your Mac's username — you can find it by typing whoami in Terminal):

launchctl load ~/Library/LaunchAgents/org.qweercoin.node.plist
What's my username? Type whoami in Terminal and press Enter — it'll print your username.

Common Questions

My balance is still 0 — is something wrong?

No — mining rewards mature after 100 blocks are mined on top of yours. If you've mined fewer than 100 blocks total, your balance will show 0. Keep going!

The mining script stopped running. What do I do?

Just paste the script again and run it. If the node stopped, run qweercoind -daemon first to restart it, then run the mining script.

Terminal says "command not found"

The installation in Step 2 may not have completed. Try running it again, paying attention to the sudo cp command and entering your password when asked.

Can I close Terminal while mining?

If you're running the continuous mining loop, closing Terminal will stop it. You can use the auto-start setup in Step 7 so the node runs in the background automatically.

Will this damage my computer?

No. Qweercoin mining is lightweight and won't harm your computer. If your fan gets loud, you can stop mining with Control + C whenever you like.
