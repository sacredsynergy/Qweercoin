Run a Node

Help keep the Qweercoin network strong and decentralised

Why run a node?

Every full node independently verifies every transaction on the network. The more nodes, the more resilient and decentralised Qweercoin becomes. Running a node is one of the most powerful ways to support the Qweer community's financial sovereignty.

1 System Requirements

OSmacOS, Linux, or Windows
RAM512 MB minimum
Storage~1 GB (growing over time)
Port9444 open (TCP)

2 Install

Download and install the Qweercoin daemon:

curl -LO https://github.com/sacredsynergy/Qweercoin/releases/latest/download/qweercoin-v0.1.0-macos-arm64.tar.gz
tar xzf qweercoin-v0.1.0-macos-arm64.tar.gz
sudo cp qwr-v0.1.0-macos/qweercoind qwr-v0.1.0-macos/qweercoin-cli /usr/local/bin/
Download Binaries

3 Start the Node

Launch the daemon:

qweercoind -daemon

Verify it's running and connecting to peers:

qweercoin-cli getblockchaininfo
qweercoin-cli getpeerinfo
The node will automatically find peers and begin downloading the blockchain. This may take a few minutes on a fresh install.

4 Auto-Start on macOS

To have your node start automatically at login, create a Launch Agent:

cat > ~/Library/LaunchAgents/org.qweercoin.node.plist <<'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>org.qweercoin.node</string>
  <key>ProgramArguments</key><array>
    <string>/usr/local/bin/qweercoind</string>
  </array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key>
  <string>/Users/YOUR_USERNAME/Library/Logs/qweercoin.log</string>
  <key>StandardErrorPath</key>
  <string>/Users/YOUR_USERNAME/Library/Logs/qweercoin.log</string>
</dict></plist>
EOF
launchctl load ~/Library/LaunchAgents/org.qweercoin.node.plist

Replace YOUR_USERNAME with your macOS username.

5 Open Your Firewall

To accept inbound connections and help other nodes sync, allow TCP port 9444 through your router or firewall. This turns your node into a public peer that others can connect to.

Check how many peers you have:

qweercoin-cli getnetworkinfo | grep connections
