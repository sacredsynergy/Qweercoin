Help keep Qweercoin decentralised and strong

COMPLETE BEGINNER'S GUIDE — NO EXPERIENCE NEEDED

What is a node?

A node is a copy of the Qweercoin software running on your computer. It connects to other nodes around the world and together they form the Qweercoin network.

Every node independently checks that every transaction on the network is valid. The more nodes there are, the harder it is for anyone to cheat or take control of the network. Running a node is a direct act of community power.

You don't need to be technical. You don't need special hardware. If you have a reasonably modern computer and an internet connection, you can run a node.

Node vs Mining: Running a node keeps the network healthy. Mining earns you QWR. You can do both at the same time — or just one. Running a node alone is completely free and uses very little power.

What you'll need

COMPUTERAny Mac, Windows PC, or Linux machine
RAM512 MB free (most computers have 8+ GB)
STORAGE~1 GB to start (grows slowly over time)
INTERNETAny broadband connection
Optionally: open port 9444 on your router to accept inbound connections. This makes you a more helpful peer but it's not required to get started.

1 Open Terminal

Terminal lets you type commands directly to your computer. You'll only need to paste a few lines — that's it.

On macOS (Mac)

  1. Press ⌘ Command + Space to open Spotlight Search
  2. Type Terminal
  3. Press Enter
Terminal — zsh
yourname@Mac ~ % ▌

On Windows

  1. Press Windows key + R
  2. Type cmd and press Enter

On Linux

Press Ctrl + Alt + T, or find "Terminal" in your app launcher.

Tip: To paste into Terminal on Mac, use ⌘ Command + V. On Windows, right-click inside the window.

2 Download & Install

Click the button below to go to the downloads page, then download the file for your system:

Download Qweercoin

macOS install

After downloading, open Terminal and run these commands one at a time — copy, paste, and press Enter for each:

↓ COPY AND PASTE — press Enter

cd ~/Downloads

↓ COPY AND PASTE — press Enter

tar xzf qweercoin-v0.1.0-macos-arm64.tar.gz

↓ COPY AND PASTE — press Enter (you'll be asked for your Mac password)

sudo cp qwr-v0.1.0-macos/qweercoind qwr-v0.1.0-macos/qweercoin-cli /usr/local/bin/
When you run the sudo command, your Mac will ask for your login password. Type it and press Enter. Nothing will appear as you type — this is normal.

Verify the install worked:

qweercoind --version
If you see Qweercoin Core v0.1.0 — perfect, installation is complete!

3 Start Your Node

Run this single command to start Qweercoin in the background:

qweercoind -daemon

You'll see: Qweercoin Core starting

After 20–30 seconds, check that it's running and connecting to the network:

qweercoin-cli getblockchaininfo

This will print a bunch of information. Look for "blocks" — this tells you how many blocks your node has downloaded.

Terminal
% qweercoin-cli getblockchaininfo
{
  "chain": "main",
  "blocks": 514,
  "headers": 514,
  "bestblockhash": "0000ab12...",
  ...
}

Check how many other nodes you're connected to:

qweercoin-cli getnetworkinfo | python3 -c "import sys,json; d=json.load(sys.stdin); print('Connected peers:', d['connections'])"
Seeing any number of connections means your node is live and participating in the Qweercoin network. Welcome aboard!
Getting "Could not connect to server"? The node is still starting up. Wait 30 more seconds and try again.

4 Auto-Start When Your Mac Turns On

This optional step makes Qweercoin start automatically whenever you log in to your Mac — so you don't have to remember to run it manually.

Find your username

First, find out what your Mac username is by running:

whoami

It will print something like sarah or devah. Remember this — you'll use it in the next command.

Create the auto-start file

Paste this whole block into Terminal, replacing YOUR_USERNAME with the result from whoami:

↓ REPLACE YOUR_USERNAME — then copy the whole block and paste into Terminal

cat > ~/Library/LaunchAgents/org.qweercoin.node.plist <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>org.qweercoin.node</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/qweercoind</string>
  </array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key>
  <string>/Users/YOUR_USERNAME/Library/Logs/qweercoin.log</string>
  <key>StandardErrorPath</key>
  <string>/Users/YOUR_USERNAME/Library/Logs/qweercoin.log</string>
</dict>
</plist>
PLIST

Then activate it:

launchctl load ~/Library/LaunchAgents/org.qweercoin.node.plist
Your node will now start automatically every time you log in. You can check it's running at any time with qweercoin-cli getblockchaininfo.

5 Help Others Connect to You (Optional)

By default, your node can connect out to the network but other nodes can't connect in to you. Opening port 9444 on your router lets others use your node too — making the whole network stronger.

How to open the port

  1. Log in to your router's admin page — usually by going to 192.168.1.1 or 192.168.0.1 in your browser
  2. Find the section called Port Forwarding (sometimes under "Advanced" or "NAT")
  3. Add a new rule: TCP, port 9444, pointing to your computer's local IP address
  4. Save and apply
Finding your local IP: In Terminal, run ipconfig getifaddr en0 (for Wi-Fi) or ipconfig getifaddr en1 (for ethernet). It will be something like 192.168.1.45.

After opening the port, check how many inbound connections you're getting:

qweercoin-cli getnetworkinfo | python3 -c "import sys,json; d=json.load(sys.stdin); print('In:', d['connections_in'], 'Out:', d['connections_out'])"

Common Questions

Do I earn anything for running a node?

Running a node alone doesn't earn QWR — but it supports the network. If you also want to earn coins, check out the Mining guide.

How much internet will it use?

Very little. A Qweercoin node uses a few MB per day when idle. Even with inbound connections open it stays modest — well within typical home broadband limits.

Terminal says "command not found"

Go back to Step 2 and re-run the sudo cp command. Make sure you press Enter after pasting and type your password when prompted.

My node had 0 connections for a while

This is normal when the network is small and growing. Give it a few minutes. You can also restart the node with qweercoin-cli stop, wait a few seconds, then run qweercoind -daemon again.

How do I know if my node is healthy?

Run qweercoin-cli getblockchaininfo and check that "blocks" is a positive number and not stuck. If it keeps growing over time, your node is syncing and healthy.

Can I run a node on a Raspberry Pi or old laptop?

Yes! Qweercoin is lightweight enough for low-power devices. A Raspberry Pi 3 or newer works well. Just follow the Linux instructions and make sure the device stays on.
